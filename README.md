# context-keeper — память проектов для Claude Code

Claude Code хранит историю сессий у себя (`~/.claude/projects/`), и если удалить сессию или проект
в приложении, весь накопленный контекст пропадает. Новая сессия в той же папке начинает с нуля:
не знает, что уже сделано, какие решения приняты и как вы любите работать.

**context-keeper** раз в день сводит свежие переписки каждого проекта в файл
`.claude/CONTEXT.md` прямо в папке проекта, а новая сессия автоматически читает его при старте.
Удалили сессию, создали новую, подключили ту же папку — и Claude продолжает почти с того же места.

## Что внутри выжимки

```markdown
# Контекст проекта: Telegram-бот для заметок
> Автовыжимка context_keeper · обновлено 2026-10-29.

## Что это за проект
## Текущее состояние
## Ключевые решения (и почему)
## Как пользователь хочет, чтобы работали
## Открытые задачи и следующие шаги
## Важные файлы, команды, окружение
## Хронология (дата — тема сессии — итог)

## Заметки вручную
<!-- ваше: скрипт этот раздел не трогает -->
```

Секреты (пароли, токены, ключи) в файл не пишутся — только где они лежат.

## Как это работает

1. **Ежедневно** (по умолчанию в 23:30; на Mac — через launchd, на Linux — через cron) скрипт
   находит все проекты по истории Claude Code, берёт сессии с прошлого обновления и вместе с
   прежней выжимкой и авто-памятью Claude отдаёт их `claude -p` (модель Sonnet). Результат —
   обновлённый `CONTEXT.md`. Проекты без новой активности пропускаются.
2. **Хук SessionStart** в `~/.claude/settings.json` при открытии любой сессии подмешивает
   `CONTEXT.md` этой папки в контекст Claude. Если выжимка старше суток (ноутбук был выключен),
   хук заодно запускает её обновление в фоне.
3. **Резервная копия** каждой выжимки — в `~/.claude/context-archive/`. Если удалить и саму
   папку, а потом создать её заново по тому же пути, контекст подтянется оттуда.

Сессии из git worktree (`.claude/worktrees/...`) относятся к основному репозиторию. В git-проектах
`CONTEXT.md` добавляется в `.git/info/exclude`, чтобы случайно не попасть в коммит.

## Установка

Нужны: macOS или Linux, `python3` 3.8+, установленный и залогиненный [Claude Code](https://docs.claude.com/claude-code).

```bash
git clone https://github.com/tlt07/context-keeper.git
cd context-keeper
./install.sh --now
```

`--now` сразу делает первую выжимку по всем проектам (≈30–90 секунд на проект). Без него
выжимки появятся ночью или при открытии сессии. Другое время: `./install.sh --time 08:00`.

Установщик можно запускать повторно — он обновит всё на месте. Перед изменением
`settings.json` делается резервная копия в `~/.claude/context-keeper/`.

## Сколько это стоит

Каждое обновление проекта — один вызов `claude -p`, он расходует лимиты вашей подписки Claude
(или API, если Claude Code работает через ключ). Проекты, где за день ничего не происходило,
не обновляются. Первый запуск по всей истории — самый дорогой. Модель можно сменить:
`CONTEXT_KEEPER_MODEL=haiku` (переменная окружения для launchd/cron).

Если Claude недоступен, скрипт не теряет материал: дописывает сырые заметки, а при следующем
успешном запуске сжимает их.

## Команды

```bash
python3 ~/.claude/scripts/context_keeper.py status                  # проекты и даты обновления
python3 ~/.claude/scripts/context_keeper.py update                  # обновить все, где есть новое
python3 ~/.claude/scripts/context_keeper.py update --project .      # только текущую папку
python3 ~/.claude/scripts/context_keeper.py update --force          # пересобрать даже без новых сессий
python3 ~/.claude/scripts/context_keeper.py update --dry-run        # показать, что будет обработано
```

Лог: `~/.claude/context-keeper/keeper.log`.

Совет: перед тем как удалить сессию, выполните `update --project <папка>` — иначе разговоры за
сегодняшний день в выжимку не попадут.

## Что не обрабатывается

- Временные сессии без папки (scratch-workspaces десктоп-приложения) — у них нет постоянного
  места для файла.
- Сессии, запущенные прямо в домашней папке `~`.

## Удаление

```bash
./uninstall.sh
```

Убирает хук, ежедневный запуск, скрипт и пояснение в `~/.claude/CLAUDE.md`. Уже созданные
выжимки остаются — удалите их вручную, если не нужны.
